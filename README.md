## Description

Système d'emprunt du matériel du BDS. Projet réalisé dans le cadre d'un défi sérieux de la campagne BDS pour la liste Totally Sport!

## Getting Started

Après avoir installé les dépendances avec `npm install`, vous pouvez lancer le projet en mode développement avec la commande suivante :

```bash
npm run dev
```
